## 1. Employee.java（键类）

```java
package cn.edu.payroll;

import java.util.Objects;

public class Employee {
    private String empId;
    private String empName;
    private int empAge;

    public Employee() {}

    public Employee(String empId, String empName, int empAge) {
        this.empId = empId;
        this.empName = empName;
        this.empAge = empAge;
    }

    public String getEmpId() { return empId; }
    public void setEmpId(String empId) { this.empId = empId; }
    public String getEmpName() { return empName; }
    public void setEmpName(String empName) { this.empName = empName; }
    public int getEmpAge() { return empAge; }
    public void setEmpAge(int empAge) { this.empAge = empAge; }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (!(obj instanceof Employee)) return false;
        return Objects.equals(empId, ((Employee) obj).empId);
    }

    @Override
    public int hashCode() { return Objects.hash(empId); }

    @Override
    public String toString() {
        return empId + " | " + empName + " | " + empAge + "岁";
    }
}
```

## 2. Salary.java（值类）

```java
package cn.edu.payroll;

public class Salary {
    private double monthlyPay;

    public Salary(double monthlyPay) { this.monthlyPay = monthlyPay; }

    public double getMonthlyPay() { return monthlyPay; }

    public void setMonthlyPay(double monthlyPay) {
        if (monthlyPay >= 0) this.monthlyPay = monthlyPay;
    }

    public void raise(double amount) {
        if (amount > 0) this.monthlyPay += amount;
    }

    @Override
    public String toString() { return String.format("%.2f 元", monthlyPay); }
}
```

## 3. PayrollBook.java（四个业务）

```java
package cn.edu.payroll;

import java.util.*;
import java.util.stream.Collectors;

public class PayrollBook {
    private final Map<Employee, Salary> ledger = new HashMap<>();

    public void loadSample() {
        enroll(new Employee("EMP-1001", "陈嘉禾", 24), new Salary(8600));
        enroll(new Employee("EMP-1002", "林知远", 27), new Salary(10200));
        enroll(new Employee("EMP-1003", "苏沐晴", 31), new Salary(6800));
        enroll(new Employee("EMP-1004", "周允诚", 29), new Salary(12500));
    }

    // 业务1：工号已存在则返回 false
    public boolean enroll(Employee staff, Salary pay) {
        if (ledger.containsKey(staff)) return false;
        ledger.put(staff, pay);
        return true;
    }

    // 业务2：工号不存在则返回 false
    public boolean dismiss(String empId) {
        Employee target = locate(empId);
        return target != null && ledger.remove(target) != null;
    }

    // 业务3：工号不存在则返回 null
    public Salary giveRaise(String empId, double amount) {
        Employee target = locate(empId);
        if (target == null) return null;
        Salary pay = ledger.get(target);
        pay.raise(amount);
        return pay;
    }

    // 业务4：Comparator 降序
    public List<Map.Entry<Employee, Salary>> rankByPayDesc() {
        List<Map.Entry<Employee, Salary>> rows =
                new ArrayList<>(ledger.entrySet());
        rows.sort((a, b) -> Double.compare(
                b.getValue().getMonthlyPay(), a.getValue().getMonthlyPay()));
        return rows;
    }

    // 业务4：Stream 降序
    public List<Map.Entry<Employee, Salary>> rankByPayDescWithStream() {
        return ledger.entrySet().stream()
            .sorted(Comparator.comparingDouble(
                (Map.Entry<Employee, Salary> e) -> e.getValue().getMonthlyPay())
                .reversed())
            .collect(Collectors.toList());
    }

    public Employee locate(String empId) {
        for (Employee key : ledger.keySet())
            if (key.getEmpId().equals(empId)) return key;
        return null;
    }

    public Map<Employee, Salary> getLedger() { return ledger; }
    public int size() { return ledger.size(); }
}
```

## 4. PayrollApp.java（菜单与键盘输入）

```java
package cn.edu.payroll;

import java.util.Map;
import java.util.Scanner;

public class PayrollApp {
    private static final Scanner sc = new Scanner(System.in);
    private static final PayrollBook book = new PayrollBook();

    public static void main(String[] args) {
        book.loadSample();
        while (true) {
            System.out.println("\n1.登记  2.删除  3.涨薪  4.降序查看  0.退出");
            System.out.print("请选择：");
            String op = sc.nextLine();
            if (op.equals("0")) return;
            if (op.equals("1")) add();
            else if (op.equals("2")) remove();
            else if (op.equals("3")) raise();
            else if (op.equals("4")) show();
        }
    }

    static void add() {
        System.out.print("工号：");
        String id = sc.nextLine();
        if (id.isEmpty() || book.locate(id) != null) {
            System.out.println("登记失败：工号为空或已存在。");
            return;
        }
        System.out.print("姓名：");
        String name = sc.nextLine();
        System.out.print("年龄：");
        int age = Integer.parseInt(sc.nextLine());
        System.out.print("月薪：");
        double pay = Double.parseDouble(sc.nextLine());
        book.enroll(new Employee(id, name, age), new Salary(pay));
        System.out.println("登记成功。");
    }

    static void remove() {
        System.out.print("要删除的工号：");
        String id = sc.nextLine();
        System.out.println(book.dismiss(id) ? "删除成功：" + id
                : "删除失败：查无工号 " + id);
    }

    static void raise() {
        System.out.print("要涨薪的工号：");
        String id = sc.nextLine();
        Employee target = book.locate(id);
        if (target == null) {
            System.out.println("操作失败：查无工号 " + id + "。");
            return;
        }
        System.out.println("当前员工：" + target);
        System.out.print("涨薪额度（元）：");
        double amount = Double.parseDouble(sc.nextLine());
        System.out.println("涨薪成功，当前月薪：" + book.giveRaise(id, amount));
    }

    static void show() {
        System.out.println("按工资从高到低（entrySet）：");
        for (Map.Entry<Employee, Salary> e : book.rankByPayDesc())
            System.out.println(e.getKey() + " | " + e.getValue());
        System.out.print("keySet()：");
        for (Employee e : book.getLedger().keySet())
            System.out.print(e.getEmpId() + " ");
        double total = 0;
        for (Salary s : book.getLedger().values()) total += s.getMonthlyPay();
        System.out.printf("%nvalues() 月薪合计：%.2f 元%n", total);
    }
}
```

## 抄写要点

1. 标点一律用半角：`;` `,` `"` `(` `)` `{` `}`，字符串内部的中文句子可以用全角标点。
2. 类名首字母大写，且与文件名一致：`Employee`、`Salary`、`PayrollBook`、`PayrollApp`。
3. 泛型尖括号要成对：`Map<Employee, Salary>`，`Map.Entry<Employee, Salary>` 中间的点不能丢。
4. `@Override` 的 O 大写，写在方法声明的上一行；漏写不报错，但属于规范问题。
5. `instanceof` 全小写，强转的括号不能省：`((Employee) obj).empId`。
6. `Objects.equals` 与 `Objects.hash` 来自 `java.util.Objects`，别写成 `Object`。
7. 降序比较器里 `b` 在前、`a` 在后；Stream 写法末尾的 `.reversed()` 容易漏。
8. `Collectors.toList()` 需要单独 `import java.util.stream.Collectors;`，`java.util.*` 不包含它。
9. 键盘输入用 `sc.nextLine()` 读整行，数字再用 `Integer.parseInt` / `Double.parseDouble` 转换。
10. 每个类写完后数一遍左右花括号；四个类的末尾各有一个单独的 `}`。

## 页数不够时的删减顺序

1. 先删 `show()` 中 keySet 与 values 的统计（约 6 行），排序结果仍完整，遍历方式改在报告正文说明。
2. 再删 `rankByPayDescWithStream()` 整个方法（约 8 行），Stream 与 Comparator 的对比写在思考题里。
3. 四条 `// 业务…` 注释可不抄，再省 4 行。
4. 不要删：`equals` / `hashCode`、四个业务方法、`Scanner` 输入，这三处是评分点。

## 与电子版的差异

- 为省行数，`Salary` 的 setter 与 `raise` 把非法参数改为“忽略”，电子版是抛 `IllegalArgumentException`；正常输入下结果相同。
- 菜单输出合并了提示语，运行效果与报告 7.3 的交互记录一致。
- 类名、方法名、初始数据、四项业务逻辑与电子版完全相同。
